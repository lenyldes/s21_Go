Комплексный репозиторий практических инженерных проектов на языке программирования Go (Golang). Коллекция охватывает ключевые направления современной Go-разработки: от фундаментальных алгоритмов и структур данных до многопоточных систем, разработки графических (GUI) и терминальных (TUI) приложений, а также проектирования веб-сервисов на базе чистой архитектуры (Clean Architecture) с инверсией управления (IoC / Dependency Injection).

---

## Обзор портфолио

Репозиторий включает 5 законченных проектов разного уровня масштаба и сложности, моделирующих реальные задачи системного программирования, backend-разработки и создания пользовательских инструментов:

1. **Алгоритмические настольные приложения (GUI):** генерация идеальных лабиринтов (алгоритм Эллера), поиск кратчайших маршрутов и моделирование пещер клеточными автоматами на фреймворке Fyne v2.
2. **Игровая логика и терминальные интерфейсы (TUI):** пошаговая игра в жанре Roguelike с процедурной генерацией подземелий, туманом войны (Field of View), искусственным интеллектом противников и модульной боевой системой на `termbox-go`.
3. **Фундаментальные основы и базовые алгоритмы:** потоковая обработка данных (`bufio`), парсинг строк, математические расчеты, частотный анализ текста, алгоритмические операции над множествами и работа со временем (`time.Time`).
4. **Конкурентное и многопоточное программирование (Concurrency):** организация параллельных вычислений на горутинах, синхронизация через `sync.WaitGroup`, потоковая передача через каналы, паттерны Pipeline и Generator, управление контекстами (`context.Context`) и корректное завершение процессов (Graceful Shutdown).
5. **Серверная архитектура и внедрение зависимостей (DI):** веб-сервис на базе чистой многослойной архитектуры (Clean Architecture / Onion Architecture) с DI-контейнером Uber Fx / Dig, структурированным логированием Zap и изоляцией доменных сущностей от транспортного уровня и хранилища.

## Ключевые компетенции и стек технологий

- **Синтаксис и стандартная библиотека Go:** эффективная работа со срезами (`slice`), хэш-таблицами (`map`), структурами (`struct`) и интерфейсами (`interface`); идиоматическая обработка ошибок (`error handling`); форматированный и буферизованный ввод-вывод (`bufio`, `fmt`, `os`, `io`); парсинг аргументов командной строки (`flag`); модульное тестирование (`testing`).
- **Многопоточность и конкурентность:** запуск и координация горутин; однонаправленные и двунаправленные каналы (`chan`); потоковые генераторы и фильтрующие конвейеры (Pipeline); примитивы синхронизации (`sync.WaitGroup`); таймауты и отмена операций через `context.Context`; обработка сигналов ОС (`os/signal`, `syscall.SIGINT`, `syscall.SIGTERM`) для реализации Graceful Shutdown.
- **Архитектурные паттерны и веб-разработка:** Чистая архитектура (Clean Architecture), принципы SOLID и инверсия зависимостей (IoC); разделение системы на независимые слои (`domain`, `application`, `datasource`, `web`, `di`); DI-контейнер `go.uber.org/fx` и `go.uber.org/dig`; структурированное логирование `go.uber.org/zap`; REST API обработчики; строгое разделение Domain-, DTO- и Storage-моделей с мапперами данных; локальные модули через директиву `replace` в `go.mod`.
- **Алгоритмы и вычислительная логика:** генерация идеальных лабиринтов алгоритмом Эллера; поиск пути в графах (BFS / волновой алгоритм); клеточные автоматы (Cellular Automata) для процедурной генерации пещер; процедурная генерация подземелий (комнаты, коридоры, размещение сущностей); алгоритмы зоны видимости (Fog of War); конечно-автоматное поведение врагов (Enemy AI, Hostility, Combat).
- **Разработка интерфейсов (GUI & TUI):**
  - Кроссплатформенный графический интерфейс на **Fyne v2** (виджеты, canvas, контейнеры, диалоговые окна выбора файлов, таймеры анимации);
  - Интерактивный терминальный интерфейс на **termbox-go** (событийный цикл Game Loop, низкоуровневая отрисовка ячеек, захват нажатий клавиш в реальном времени).

## Требования и инструкции по сборке и запуску

### Системные требования
- **Go:** версия 1.22 или выше (рекомендуется Go 1.24+);
- **Системные библиотеки для GUI (проект Maze):** поддержка OpenGL, компилятор C (gcc) и библиотеки разработки для Fyne (на Linux: `libgl1-mesa-dev`, `xorg-dev`).

### Запуск проектов

1. **Клонирование репозитория:**
   ```bash
   git clone <url-репозитория>
   cd <каталог-репозитория>
   ```

2. **Запуск графического приложения Maze (Проект 01):**
   ```bash
   cd A1_Maze_Go_ID_1391788-Team_TL_maryamer_96897b51_c272_4712-1-develop/src
   make install
   ./build/maze
   ```

3. **Запуск терминальной игры Rogue Game (Проект 02):**
   ```bash
   cd AP1_Go_P01.ID_1375361-Team_TL_tyananai.bbb98297_c374_40a6-1-develop/src
   go run ./cmd/game/main.go
   ```

4. **Запуск задач по многопоточности (Проект 04):**
   ```bash
   cd AP1_Go_T02.ID_1375360-2-develop/src
   go run ./ex01/main.go -N 5 -M 100
   go run ./ex02/main.go -K 1 -N 50
   go run ./ex03/main.go -K 2
   ```

5. **Запуск веб-сервиса на Clean Architecture и Uber Fx (Проект 05):**
   ```bash
   cd AP1_Go_T03.ID_1364928-2-develop/src/di/cmd
   go run main.go
   # Сервис доступен в браузере по адресу: http://localhost:8080
   ```
