Репозиторий представляет собой комплекс практических решений на языке программирования Go, ориентированных на демонстрацию фундаментальных алгоритмов, структур данных и идиоматических паттернов стандартной библиотеки. В рамках проекта реализованы четыре независимых консольных приложения: интерактивный валидирующий калькулятор, анализатор частотности слов с многофакторной сортировкой и модульным тестированием, алгоритмически оптимизированное пересечение мультимножеств и картотека учета посещений специалистов с валидацией хронологических данных.

## О проекте

Проект разработан в рамках курса Go Bootcamp и нацелен на отработку ключевых инженерных практик разработки на Go:
- Строгое соблюдение принципа нулевых внешних зависимостей (Zero External Dependencies) исключительно на возможностях стандартной библиотеки Go.
- Корректная и устойчивая обработка потокового ввода данных через системные потоки (`os.Stdin`, `bufio.Scanner`) с циклической валидацией пользовательских ошибок и обработкой сигналов завершения потока (`io.EOF`).
- Эффективный выбор структур данных и алгоритмов с контролируемой вычислительной сложностью: применение хэш-таблиц (`map`) для достижения линейного времени выполнения O(N + M) при сопоставлении коллекций, реализация пользовательских компараторов в срезах структур.
- Проектирование предметных моделей данных с использованием структур (`struct`), кастомных типов ошибок и стандартных протоколов работы со временем (`time.Time`).
- Обеспечение надежности кодовой базы посредством модульного тестирования с применением табличной методологии (Table-Driven Tests) и проверки граничных состояний.

## Ключевые навыки и освоенные концепции

В процессе реализации кодовой базы применены и закреплены следующие инженерные концепции:

- **Потоковый ввод-вывод и работа с терминалом**: Чтение непрерывных потоков строк через `bufio.Scanner`, чтение и парсинг терминальных команд, перехват ошибок ввода и корректная обработка маркеров конца файла (`io.EOF`).
- **Преобразование типов и валидация данных**: Парсинг строковых литералов в вещественные и целочисленные типы (`strconv.ParseFloat`, `strconv.Atoi`), валидация допустимых диапазонов и наборов операторов, устойчивость к некорректным пользовательским данным.
- **Работа со временем и датами**: Разбор строковых представлений дат по эталонному шаблону `2006-01-02` с помощью `time.Parse`, форматирование дат через метод `Format()`, хронологическое сравнение меток времени посредством `time.Before()`.
- **Хэш-таблицы и словари (`map`)**: Использование ассоциативных массивов для быстрого поиска и подсчета частот (`map[string]int`, `map[int]int`), хранение связей один-ко-многим с коллекциями структур в качестве значений (`map[string][]pationVisit`).
- **Срезы (`slice`) и динамическая память**: Аллокация и управление срезами, динамическое наполнение через `append`, ограничение выборки с помощью функции `min()` и срезовых выражений.
- **Сортировка и пользовательские компараторы**: Применение `sort.Slice` для реализации составной двухфакторной сортировки: первичная сортировка по убыванию частоты вхождений, вторичная — по возрастанию в лексикографическом (алфавитном) порядке.
- **Пользовательские структуры и объектная модель**: Определение доменных сущностей (`Word`, `pationVisit`), композиция данных, инкапсуляция полей в рамках пакета.
- **Обработка ошибок (Error Handling)**: Идиоматическая проверка `err != nil`, реализация пользовательских типов ошибок через интерфейс `error` (`PatientNotFoundError`), инспекция ошибок через `errors.Is`, обработка критических вычислений (проверка деления на ноль с учетом машинного эпсилон `1e-6` через `math.Abs`).
- **Модульное тестирование (Unit Testing)**: Разработка тестов с использованием стандартного пакета `testing`, организация сценариев по методологии Table-Driven Tests с вложенными подтестами `t.Run`, глубокое сравнение структур и срезов через `reflect.DeepEqual`, всесторонний охват граничных условий (пустые входные данные, предельные значения K, дубликаты, пробельные символы).

## Архитектура и стек технологий

Проект построен как монорепозиторий независимых модулей, использующих исключительно официальный инструментарий и стандартную библиотеку языка Go 1.25.

Используемые модули стандартной библиотеки:
- `bufio`: Буферизованный построчный ввод данных из стандартного потока `os.Stdin`.
- `os`: Низкоуровневое взаимодействие с операционной системой, обработка потоков ввода-вывода, управляемый выход из программы через `os.Exit`.
- `fmt`: Форматированный вывод данных, отображение строк, форматирование чисел с плавающей запятой с заданной точностью.
- `strconv`: Преобразование строковых литералов в базовые числовые типы (`ParseFloat`, `Atoi`).
- `strings`: Токенизация текста с разделением по пробельным символам (`Fields`), удаление лишних концевых пробелов (`TrimSpace`).
- `sort`: Сортировка коллекций произвольной структуры на основе замыканий и предикатов (`sort.Slice`).
- `time`: Строгая типизация дат, синтаксический анализ строковых форматов, хронологическое сопоставление.
- `math`: Математические операции и расчет абсолютного отклонения для безопасного сравнения с плавающей точкой (`math.Abs`).
- `errors`: Создание и идентификация ошибок на соответствие целевым типам (`errors.Is`).
- `testing`: Автоматизация модульных проверок и бенчмарков, регистрация диагностических сообщений об ошибках.
- `reflect`: Рефлексивное глубокое сравнение составных типов данных (`reflect.DeepEqual`).

## Инструкция по сборке и запуску

### Системные требования
- Установленный компилятор Go версии 1.25 или выше.
- Операционная система семейства Linux, macOS или Windows.

### 1. Калькулятор (Задание 01)
Запуск интерактивного калькулятора:
```bash
go run src/01/main.go
```
Пример взаимодействия:
```text
Input left operand:
15.5
Input operation (+ - * /):
/
Input right operand:
2
Result: 7.750
```

### 2. Частотный анализатор слов (Задание 02)
Запуск анализатора текста:
```bash
go run src/02/main.go
```
Пример взаимодействия:
```text
aa bb cc aa cc cc cc aa ab ac bb
3
cc aa bb 
```

Запуск набора модульных тестов для частотного анализатора:
```bash
cd src/02 && go test -v ./...
```

```bash

```
Пример взаимодействия:
```text

```

### 4. Система учета визитов к врачам (Задание 04)
Запуск интерактивной консольной картотеки:
```bash
go run src/04/main.go
```
Доступные команды в интерактивном цикле:
- `Save`: Добавление новой записи (запрос ФИО пациента, специализации врача, даты в формате YYYY-MM-DD).
- `GetHistory`: Отображение полного списка всех посещений конкретного пациента.
- `GetLastVisit`: Поиск даты последнего визита пациента к врачу определенной специализации.
- `q`: Завершение работы программы.
